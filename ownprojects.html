PyRADTEMCam

Radiometric calibration system for thermal infrared cameras mounted on UAVs. Combines IoT sensor nodes with LoRaWAN communication, calibration panels, and a Python correction model — reducing temperature error from 6°C to <0.5°C.

Python Dash GIS

SIGPAC Parcelas

A web application for downloading SIGPAC agricultural plot vectors across Spain. Supports selection by individual parcel codes, interactive map drawing, and advanced filters (area, slope, land use). Exports directly to GeoPackage and Shapefile formats.
